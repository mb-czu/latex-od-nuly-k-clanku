# Krok 2 - Instalace

> [!NOTE]
> [Zpět na instalační manuál](README.MD)

Na macOS i Windows existuje několik možností instalace LaTeXu. Vyber si svou možnost dle operačního systému, dostpné kapacity atp.


| OS      | Distribuce                                                   | Doporučení                                   |
| ------- | ------------------------------------------------------------ | -------------------------------------------- |
| macOS   | [BasicTeX](./možnosti-instalace/macos-basictex.md)           | Pro ty, kteří chtějí menší instalaci         |
| macOS   | [MacTeX](./možnosti-instalace/macos-mactex.md)               | Pro ty, kteří chtějí vše připravené          |
| Windows | [TeX Live (Full)](./možnosti-instalace/tex-live-windows.md)  | Pro ty, kteří chtějí vše připravené          |
| Windows | [TeX Live (Basic)](./možnosti-instalace/tex-live-windows.md) | Pro ty, kteří chtějí menší instalaci         |
| Windows | MiKTeX                                                       | Alternativa s automatickou instalací balíčků |

> [!NOTE]
> Já osobně pracuji na MacOS s BasicTeX.
> Pro instalaci na Windows doporučuji TeX Live (varianty se liší v rámci instalačního průvodce).
